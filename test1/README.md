# 369 게임

어떤 자연수를 제시하면 그 수를 십진법으로 표기했을 때의 숫자들 중 3, 6 그리고 9에 해당하는 숫자의 개수만큼 박수를 치는 게임이 있습니다. 예를들어 "31"의 경우 박수를 한 번, "619"는 두 번, "1024"의 경우 박수를 치지 않습니다. 이 때 1부터 시작하여 2, 3, 4, ..., N 까지 이 규칙을 적용하여 박수를 쳤을 때 박수 횟수의 총 합을 구하는 함수 "uint64_t Solution(uint64_t N);"을 파일 "test1.cpp"에 구현하여 다음 "입력/출력" 사항을 만족시키세요.

### 입력/출력
프로그램을 실행시킨 후 첫 줄에 자연수 N을 입력하면 다음 줄에 박수 횟수의 총합이 출력되도록 합니다.

예1)
```
20
```
```
6
```
예2)
```
30
```
```
10
```

## 제약사항

N은 최대 $10^{18}$ 인 자연수이며 임의의 N에 대해서 실행시간은 1초 미만이어야 합니다. 

### 힌트
복잡도를 $O(N)$으로 만들면 위 제약사항을 만족할 수 없으므로 $O(log N)$ 이 되도록 알고리즘을 설계해야 합니다.
